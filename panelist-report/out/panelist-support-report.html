  1. Demand concentrates in Hardware & Meter322 of 900 cases (35.8%) carry Hardware & Meter as their primary category. The top two buckets together account for 51.7% of all contacts.
  2. Cases are multi-issue, so single-category routing understates real demandCases carry 3.02 category tags on average and 82.9% carry more than one (14 distinct labels in use). Counting only the primary category hides 1820 secondary topic tags that agents still had to handle.

Date caveat carried through the whole report
No case-creation timestamp is present, so every time-based figure uses Modified On. That records the last time a case was touched, not when it arrived — a case opened in March and reopened in July counts as July. Trend direction and any "within N days" sequencing should be read with that distortion in mind.

Leading indicators worth instrumenting

  • Topic tags per case — currently 3.02. A rise means single contacts are absorbing more unresolved issues; it moves before handle time and before CSAT.
  • Share of volume from repeat members — 97.8%. Rising repeat share is the earliest sign that first-contact resolution is failing.
  • Reactivation and activity-inquiry share of primary category — the closest available proxy for panelists drifting toward involuntary purge.
  • Outbound / callback share — a rise indicates inbound channels are not closing issues on first contact.

If nothing changes

The fitted trend carries volume to roughly 216 cases in 2027Q2 (range 184–248) with the current mix intact — that is the do-nothing baseline against which any intervention should be measured.

5Strategic recommendations & action plan

Priority 1Quick win (0–30 days)Owner: Support Ops / CRM administration

Add 5 missing field(s) to the case export

The export currently supports volume and mix analysis but blocks several causal tests outright. Adding these fields costs a report definition change, not a system change: Created On / case-open timestamp — Every trend, seasonality and 'within N days' figure in this report is currently anchored to Modified On, which records last touch, not arrival.; Office / site — No site-level breakdown of volume or mix is possible.; Agent / case owner — No handling-side variance analysis is possible.; member type / household role (primary vs secondary) — Secondary-member lockout and household attrition are NOT computable without a member-type or household-link field.; enrollment or join date (for 30/60/90-day tenure) — Early-life churn is NOT computable without an enrollment date; tenure cannot be derived from case dates alone..

Attack the Hardware & Meter driver first

Hardware & Meter is the largest single primary category at 35.8% of cases (322 of 900). Any deflection built here has the widest reach; the associated exposure is panel data loss, cost-to-serve.

Split the multi-topic case into countable units

At 3.02 tags per case and 82.9% of cases multi-tagged, a single case can conceal an equipment fault, a reward dispute and a password reset at once. Either capture a required primary reason with explicit sub-reasons, or emit one case line per topic, so demand sizing and AHT attribution stop disagreeing.
